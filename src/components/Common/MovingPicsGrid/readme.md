MovingPicsGrid - "бегущая" сетка из изображений.

Сетка формируется из элементов Marquee - "бегущих" строк из изображений.
Количество строк, высота строки, параметры искажения и поворота сетки
рассчитываются исходя из заданных параметров:

1.  slantAngle: number - угол наклона сетки в градусах
2.  gammaAngle: number - угол искажения сетки в градусах
3.  speed: number - скорость прокрутки сетки в пикселях в секунду

Для расчёта зависимых параметров используются следующие утилиты:

1. getDiaShapeParams [@/utils/MovingPicsGridUtils/getDiaShapeParams]
   утилита для расчёта ширины, высоты и параметров искажения компонента сетки

2. getNRowParams [@/utils/MovingPicsGridUtils/getNRowParams]
   утилита для расчёта парметров заполнения сетки: количество рядов, число
   элементов в ряду
